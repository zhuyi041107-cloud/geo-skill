# 报告分析与执行规划思路

这是给WorkBuddy的内部工作指引，不是客户报告的章节。客户应看到现状、判断依据、业务含义和具体方案，不应看到一份“如何诊断”的说明书。

直接替换原模板的客户内容，平台判断用具体平台及需求场景归属表达。不要把内部证据规则、采集条件、回答条数、观察基础或本文件的说明段落复制进客户正文；具体业务事实的确认条件在对应事项旁说明即可。

## 一、先把客户的实际选择链看清

从客户主营、目标客群和目标区域梳理：用户先遇到什么需求，在AI中怎样找候选，选择前会比较什么，需要哪些事实才愿意信任。只分析与客户目标直接相关的链条，不因为行业有某个术语就额外展开。

将客户的真实能力、已公开资料和AI回答分开：

- 客户填报说明客户希望表达什么，资质、规模、案例、收费承诺等仍需有材料支撑。
- 答案与截图说明本轮平台怎样呈现品牌及其他候选。
- 两者的差异才是诊断的入口：该被理解的服务未出现、主体被混淆、关键承诺多说或说错、需求场景被竞品占据等。

## 二、诊断不是把采样表抄进报告

每个主要判断至少说清“当前发生了什么、对客户的选择入口意味着什么、应该优先改哪一块”。引用现有材料支持判断，避免只有“覆盖弱/需优化/提升认知”这样的标签。

### 需求入口

自然需求问题里，品牌是否进入候选、是否被推荐、在哪类用户和场景出现？将不同客群的表现分开，找出真正影响业务的入口缺口。问通用核验知识时没有提及品牌，不必自动当成品牌推荐失败。点名题里出现了品牌，更不能当成自然获客成功。

### 品牌理解与事实一致性

看答案是否理解客户核心服务、适用对象和地域边界。把公司主体、商标、APP、关联品牌与域名分别看待，不能混为一个运营主体。成立时间与上线时间也不是同一件事。具体收费、审核、保障和资质承诺超出客户材料时，指出“表述超出已知依据”，不要替客户确认或简单判错。

### 竞品与替代渠道

只比较本轮答案实际出现的主体及其出现情境，说明它满足了用户什么需求、客户当前缺哪类相应内容或证明材料。不能把并列列举当排名，不能无根据说某竞品更受算法偏爱。

### 引用来源结构

从截图识别可见来源标题、站点与内容角色：官网事实、应用上架介绍、品牌发布稿、独立行业报道、岗位/本地信息等。区分“第三方承载平台”和“独立第三方评价”；应用商店或转载站承载品牌内容，不等于独立背书，也不能全部叫客户自有资产。

截图数、可见来源条目数、去重来源数是不同数字；同一截图可以有多条来源，同一来源也可能重复。看不清不编数。缺少URL时仍可分析截图中可见结构，正文是否支持某一事实保持局部未确认，不把报告写成链接核验说明。

### 结论的边界

“本轮未见某案例被引用”只能说明本轮观察，不证明页面不存在、未被索引或这就是未被推荐的原因。建议补充稳定案例页可以作为执行动作，但不能把推测写成已证明的因果。不要写平台内部权重、置信度、固定采信规则或必定生效周期。

## 三、把问题逐项转成执行方案

对每个优先缺口形成一条可执行链：

**目标需求/当前问题 → 要形成的品牌认知 → 关键词与选题 → 需要的事实材料 → 内容载体 → 实际媒体 → 发布次数与时间 → 费用 → 交付检查。**

- 主体或服务口径不清：先整理官网事实、公开资料与一致表述，再安排第三方承载；不要用更多媒体重复错误口径。
- 本地/具体服务场景弱：将真实地域案例、服务流程和适配条件写成能直接回答用户选择的问题内容，而非堆公司宣传语。
- 需求入口缺席：优先提供用户视角的选择说明、案例和问题答案；品牌露出要自然，不能虚构竞品对比、优势或排名。
- 信源单一：补充适合该内容的独立媒体和公开信息入口，保持原创事实可追溯；同稿多站转载是传播次数，不是多份独立佐证。

## 四、选媒必须落到具体资源

先查随包媒体目录，按业务/客群/地域/稿件形态找候选，再检查媒体备注与题材限制。明确不发GEO或不接受本次题材的资源排除。媒体名称中的具体栏目保留，不能把内部供货渠道/负责人当刊发栏目。

按角色组合合适的媒体：品牌事实和公信承载、行业/招聘需求理解、地方场景、目标客群常见内容平台。角色适配比堆砌“央媒、权威、AI友好”标签重要；没有依据时不把某媒体写成必收录、必引用。

方案每条选用媒体写明：具体名称和实际刊发形态、要承载的文章、选用理由、参考价、次数、预计费用和执行时间。媒体来源必须能回到目录记录；不要生成不存在的媒体、TBD或只有类型没有名称的空清单。

## 五、排期、预算和效果要形成闭环

按客户周期安排阶段与自然季度，先解决事实与基础内容，再覆盖需求场景、媒体分发和维护。稿件数量与媒体次数由实际任务推导，不照抄历史案例的篇数；同一篇多站发布只记一篇内容、多次刊发。

从内置市场参考价计算建议媒体发布预算，标明报价日期与费用范围。代理成本、已确认客户售价和市场参考价不是一个口径。服务费未给出时明确是否计入，不能以已知媒体小计冒充全年综合费用，也不能让整份预算全是待报价。

效果分为能交付的内容/刊发/页面/排期，和后续应观察的品牌理解、需求入口及来源变化。目标符合客户业务基础，不预设转化、流量或AI排名保证。

## 六、客户成品检查

先读一遍成品正文：它是否说明客户现在的情况，是否分析了真实差距，执行方是否能据此做内容、选媒体、排期和核算？若主体仍是方法教程、后台ID、空占位表、泛类型媒体或无依据承诺，就继续修改，不交付。

客户PDF保留随包原模板的章序、图表和表头，只替换业务内容；内部证据和流程留.work，不新增采样基础或方法段落。默认交两个PDF和原格式推荐媒体Word，内部核算不作为客户附件。
