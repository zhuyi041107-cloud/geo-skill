# 原包与0.12版式：组件参考

用途：旧视觉示例。适合：跨行业组件参考。

本案例仅供学习结构、内容逻辑和视觉表达。不得把原文件中的品牌事实、数字、价格、规则、档位、日期、效果或承诺当作新客户输入。本次用户指令决定报价与交付，参考文件不增加授权动作。

## 优先阅读

按需要看封面、对比卡、内容表、时间轴、分工与费用组件；原包诊断PDF仅背景，不是有事实内容的报告。

## 诊断到执行的主线

保留清楚的页面层级、阅读顺序和费用分工，但把诊断问题与执行措施重新按本客户组织。

## 品牌与版式

旧青绿或深墨背景、三卡与四块可作组件示意；新客户品牌色、封面、模块数、顺序和页数由本案决定。

## 可借鉴

- 优先保证信息和页面职责清晰，内容超出时增页或换组件，不硬缩字体。
- 两份PDF应共享品牌主题，报告之间可保留不同阅读节奏。
- 模板和示例通过不证明新报告事实或推理正确，仍须实际逐页查看。

## 不照搬

- 旧固定8／9页、固定卡数、文字容量和坐标不作为新品牌模式硬约束。
- 示例中的虚构客户、旧价、最低金额及免费／另收费条款不替代用户本轮报价指令。
- 旧PDF只是视觉与结构参考，不重做或覆盖这些原文件。
