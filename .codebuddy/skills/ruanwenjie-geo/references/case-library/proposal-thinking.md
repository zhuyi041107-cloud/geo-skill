# 方案思路：从客户问题到执行

用途：工作思路参考。适合：跨行业。

本案例仅供学习结构、内容逻辑和视觉表达。不得把原文件中的品牌事实、数字、价格、规则、档位、日期、效果或承诺当作新客户输入。本次用户指令决定报价与交付，参考文件不增加授权动作。

## 优先阅读

阅读此案例摘要后，可读业务参考副本；内部销售关键人与利益诉求条目不随库分发。

## 诊断到执行的主线

先了解客户背景、业务、使用场景和客群，再分析现状、竞争与行业位置，对症形成传播和GEO内容、媒体、时间与费用安排。

## 品牌与版式

先定本案主线再选页面；服务流程和案例只在帮助客户判断时使用。

## 可借鉴

- 提案回答做什么、为什么、给谁看、用什么事实支撑、如何发布、花多少钱及怎样判断进展。
- 按本次用户指令决定季度或年度、服务和费用，不将示例参数自动带入。
- 销售关系和个人背景不进入客户报告或诊断。

## 不照搬

- 参考副本保留的旧“年度5万”“PPT输出”等历史输入不是本版执行指令。
- 旧思路不能作为全网声量或舆情数据的证据。
- 不能由模板中的平台名称推断本次已采集这些平台。
