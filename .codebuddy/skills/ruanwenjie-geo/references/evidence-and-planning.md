# 证据、媒体与费用规则

## 事实与实际观察

内部判读分别记录客户填报、可核公开事实、AI实采与分析判断，保留原件位置、sample_id、截图及已有URL。主体、统计时间、产品版本、单位和适用范围一致；公司、产品、历史主体和关联品牌不混用。最新客户纠正更新其明确范围，企业自述不自动升级为独立验证。

AI完整原答支持本平台的认知与推荐分析；缺引用时仅相应信源结论保持未核，不能因此否定全部认知判断。点名提及、自然候选、明确推荐和优先选择分开；列表次序不等于市场排名，AI解释自己为何推荐不作真实机制证据。

“未展示引用”不证明没有检索或使用其他来源；“未见某页面被引用”不证明页面不存在、未被索引或就是未推荐的原因。材料空白、检索未见、AI未提及分别记录。多站转载同一内容是分发覆盖，不是多份独立证实；付费刊登也不自动成为独立背书。

### 人工截图与采集条件

三列表不要求同事记录URL、时间、模式、联网及新对话状态。缺项按本轮日期、网页端联网的业务约定内部整理，保留约定来源及未知，不冒称实际联网已核或编造精确模型、时分秒；明确历史记录优先。收到单平台即完成该范围报告，不要求补齐平台或条件。

截图可支持界面可见标题、站点、来源条目和分布分析。没有完整URL时记录截图位置及可读信息，正文是否支持具体事实保持未知；获得URL后再按实际材料核验，不另要求同事抄链接。看不清不编数，未知不当0，不把无URL变成交付门槛。

上述证据规则留.work。客户正文写品牌现状、业务影响及行动；必要未知在对应业务事项中转成具体配合或确认内容，不追加采集过程和样本免责声明。

### 内部指标

仅在判断需要且分母有效时计算，保留分子、分母及未判／失败状态：

| 指标 | 口径 |
| --- | --- |
| 自然提及 | 不带客户品牌的自然需求题中，有效且已判读的品牌提及表现；点名题分开 |
| 明确推荐 | 推荐意图问题中，明确推荐客户的数量与已判读有效数量；与普通提及分开 |
| 可观察支持引用 | 可比展示条件下，已核正文确实支持相关品牌事实的引用；仅可见截图不算正文已核 |
| 事实准确性 | 逐项列正确、错误与未知及依据；没有完整核验范围时不造准确率 |
| 场景与来源 | 按实际问题意图列场景表现；来源条目、唯一URL、域名和独立内容分开 |

分母为0时值为null，内部显示不可计算。按已有条件区分平台与题型，不混用不可比结果。有限AI样本不推全网声量、稳定概率、全平台认识或全网无负面；需要其他结论时须有相应材料，不能用笼统免责声明保留过度结论。

## 媒体选择与双sheet推荐池

默认使用随包media-catalog.csv.gz，不要求同事重传媒体报价。目录保留身份、分类、地域、限制、原记录索引和六档原价；用户提供有来源及日期的更新报价时优先，不混用不同版本。市场参考价、内部成本和已确认客户售价分别保存。

先按业务、客群、地域、题材及刊发条件广泛查询网络媒体、自媒体，使用media.py的`--limit 0`取尽相关匹配后筛选，不只查看默认前30条。明确拒发或不适配的排除，有限制及待确认资源保留真实备注；未知不能说已确认可发，也不把不相关整库灌入。

plan.media_recommendations是独立推荐池，按source_sheet与media_id去重，保留适配理由及原价。推荐数量、资源单价总和不受执行预算、稿数或发布量限制；plan.placements才是预算内实际执行子集。完整Excel规范见 [推荐媒体输出](media-word-output.md)：sheet1网络媒体、sheet2自媒体，原16/17列与六档价格，目录缺价才留空，不按折扣反算。

客户方案说明具体媒体／栏目、内容用途、发布量及适配理由。门户名、媒体价格或商业档位不自动证明权威身份、独立背书或AI收录能力；刊发建议不等于已确认接稿、下单或已发布。供应商、实际联系方式和毛利不进客户文件；表内“联系方式”表示稿件能否带联系方式的政策。

## 内容数量与阶段

独立稿数按内容组的有效任务形成，不凑整、不平均分配。相同事实可以支持不同采购判断，换标题或地名、重复简介、几句FAQ不自动增加独立稿。一篇实质支持多个认知目标仍只计一篇；同稿多站分别统计一篇内容和多次发布，额外增发须有明确任务与同意。

售前先有内容组、独立稿数、发布量、阶段及费用的内部规划，客户展示方向与规模，不强制提前列全逐篇文章和每周排期。合作后细化承接实际成交版本与权益，改规模同步核内容、阶段、媒体、周期及金额，保留旧→新关系。

阶段从真实优先场景、事实成熟度和工作依赖确定，不统一套先品牌介绍、后场景推荐。已有事实足够的场景稿可先开展，官网修正可并行；缺料只影响对应主张或内容，不拖住全部任务。年度项目按确认范围说明全年建设与维护，不能把短期媒体包称全年综合服务；季度核算用实际日期，未定日期内部记未排期。

## 约2万元实际执行预算

本轮明确预算优先。未另给预算时，project.budget_target与budget_limit均为20,000元，旧项目的null不能漏掉本轮默认；正式建议已知费用通常为18,000—20,000元。明确只给上限且允许少花时目标可为空，按该约束执行。

预算只包括实际placements及确已约定的其他费用。先保证诊断主缺口和有价值内容，再比较媒体配置；推荐池的资源总标价不算客户支出。不按季度均摊，不用维护、重复稿、机械增发、抬单价或虚构管理费凑金额；资源和素材确有限制时说明具体取舍，不能把两千元的零散投放当约2万元完整方案。

从目录测算建议预算时保留market_reference_price，并同值写client_unit_price，注明市场参考价、报价日期与执行价待确认的实际状态；unit_price未知仍为null，不把市场价填成内部结算成本。已有明确客户售价优先。金额用十进制两位，媒体费＝实际单价×次数，其他费用有范围及报价才计入，取消／排除项不计。

缺价保留已知小计及具体缺项，不把未知当0。税费、撰稿、页面建设、复核或维护是否包含按实际约定写清；未报价服务不写成已含刚性交付。综合总预算要为已知服务费留空间，不能先花满媒体费再加收费。本技能不迁移新包的媒体价格区间、承接底线、财力调查或写稿单价默认。

普通／高权重仅在确有两套实际计划时展示。同内容两档保持独立稿数与内容标准一致，差价来自可追溯媒体配置，同内容两档也保持发布量一致；不为做双卡强加稿件或虚构第二档。

医药、医疗健康等敏感行业及用户指定行业，按实际承接范围规划与发布，客户负责撰稿、专业审核、定稿和公开授权；方案不含人工／AI代写、免费改写或写稿费用。不自行扩列全部受监管行业。

## 费用与结果验收

从内容组追到阶段、独立稿数、发布次数与金额，正文、总览、明细和费用同源。内容稿数＝阶段稿数＝总稿数，媒体／阶段发布量＝实际发布明细；调整前后金额差额能对应任务、媒体、数量或明确优惠，不能只把总价改对。

可承诺工作按真实范围列内容、发布、交接和阶段复核；品牌事实采用、自然推荐与排名方向须按实际结果观察，曝光、咨询和成交无可靠数据时不给数值保证。交付验收与效果观察分开，未执行建议不作已完成结果。

客户成品只交两份PDF及推荐媒体Excel。内部analysis/plan、证据与核算不作为附件。所有文件生成后按 [交付前自审](template-generation.md#7-交付前另轮自审) 检查最终版，实际未检查项如实记录。
