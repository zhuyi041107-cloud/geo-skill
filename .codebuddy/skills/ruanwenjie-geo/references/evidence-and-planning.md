# 证据、诊断与执行规则

## 证据分层

内部判读分别记录客户填报、网页核验、AI实采和分析推断，附sample_id、已有URL和支持事实。证据管理规则与采集限制留在.work，不写成客户方法前言；报告对具体资质、主体或承诺的确认条件在对应事项旁说明。多站转载同一内容不能算多份独立佐证。

“未展示引用”只说明采样界面没有可观察引用；不证明平台未检索或未使用其他来源。品牌名称字符串出现后，核对同名公司、否定推荐、引用上下文和是否为客户主体。算法规则、推荐权重、必定收录周期等仅在有对应平台一手资料时表述为已知事实。

## 指标（内部核算）

以下口径用于后台判读与核算，不自动生成客户指标表、采集声明或样本解释。只有原模板存在对应数字栏时才填该栏；客户正文写具体品牌表现及业务意义。

| 指标 | 口径 |
|---|---|
| 自然提及率 | 自然需求题中，已判读为提及的有效样本 / 已完成提及判读的有效样本；同时披露待判读数与全部有效数 |
| 推荐率 | intent为推荐的有效样本中，明确推荐该品牌的数量 / 已完成推荐判读的数量；自然与点名分开 |
| 可观察引用率 | 在相同联网、支持引用展示条件下，存在已核验且支持品牌事实来源的样本 / 已完成来源判读的可比有效样本；未展示来源计无可观察引用，未核验项待判 |
| 事实准确性 | 逐条列已核实正确、错误和未知事实及依据；没有完整核验范围时不造准确率 |
| 场景覆盖 | 按问题意图、业务和地域列出现/缺口，展示样本与证据 |
| 信源分布 | 引用次数、唯一URL、域名、原始内容归属与媒体类型；引用次数不等于独立证据数量 |

按平台、模式、联网、轮次、题型、意图分组；展示分子、分母、有效/失败/未采/待判数量。分母为0时数值为null，显示“待采集/不可计算”，不显示0%。待判样本比例大时先补判或标为部分结果。

三列表不要求人工记录时间、模式和新对话状态。缺少明确记录时沿用用户约定：当前本轮日期、AI网页端联网提问；内部标明约定来源，保留已有明确的历史记录，不编造具体模型或时分秒。不因未填这些列停止交付，也不追加补记任务；只依据已有材料报告本轮表现，不宣称严格控制实验或跨平台稳定表现。

引用截图可作为“界面可见引用”的证据。看不到完整URL时记录可见标题/网站和截图位置，正文核验保持未知；不要求用户另抄链接。内部引用URL为空时必须有可追溯截图证据并保持待核验，不能算已核验支持引用，亦不能把未知当0。只在实际获得URL时校验URL格式和内容。

截图足以支撑可见来源的数量与分布观察，无URL不阻断诊断报告和执行方案。正文未核验仅在相关事实或指标旁简短标注，不以此要求额外采集。本轮没有引用某个客户页面只能写“本轮未见该来源”，不能直接断言该页面不存在、未被索引或缺页就是未被推荐的原因；可将补充案例落地页作为执行建议。

AI样本不能推出全网总声量。需要全网现状时补充可追溯的公开检索记录（搜索词、引擎、日期、结果URL、摘要及去重主题）或真实监测导出。负面结论附原文上下文、时间及主体核对；无检出写“本次样本未检出”，不写“全网无负面”。

## 媒体筛选

默认使用随包media-catalog.csv.gz，不再要求用户另传媒体表。目录保留真实媒体及原记录索引、可发限制和市场参考价；用户另提供更新报价时优先用新文件。市场价、代理成本和客户确认售价分开，不能将内置市场价当成内部结算成本，也不重算折扣。

先按主题、地域、媒体类型与预算形成候选，再检查备注：明确不发GEO的排除；仅限制GEO对比测评等内容形态的先标为需核实，匹配本次稿件类型后再决定；可疑备注不能悄悄忽略。未知属性保持待核实，不能等同不符合或编造认证。媒体类别、名称和价格不构成党央媒身份或AI收录能力的证据。

`media.py`辅助检索候选和显式限制，WorkBuddy根据业务目标选择实际资源并写理由。媒体名称中的真实栏目保留，供应商/供货渠道/负责人不是刊发栏目。方案按目录报价日期给出参考预算和发布条件；不能因未做实时询价而整页只写“媒体类型/待报价”。媒体AI引用能力若无证据保持未确认，不承诺必被收录或引用。

## 内容与年度执行

每个content_id关联目标问题、事实材料、文章方向、受众、预计时间；每个placement_id关联内容ID、媒体ID/渠道、报价来源、次数、单价与状态。传播任务与GEO任务共用内容/刊发时只计一次费用。

依次补主体事实、可验证的案例/专业内容、第三方与行业信源、具体需求场景，再复测维护。具体量级取决于现有缺口、预算和媒体限制，不照搬案例中的篇数、行业评分或周期。

季度使用实际执行日期的自然季度。跨年项目同时标年度；未定日期进入“未排期”。内容篇数按不同content_id计，刊发次数按有效刊发明细数量之和；不要把候选资源数量当已选数量。

## 预算与客户版本

内部媒体费=原报价单价×刊发次数；其他费用单列。对客单价、对客费用必须明确填写，不能自动把内部成本当客户售价。Decimal保留两位金额；缺价总额显示待确认，已知小计与缺项数量分别展示。取消/排除的项目不计入执行总额，候选与已选状态明确区分。

本轮目标金额写budget_target，费用上限写budget_limit；按template-generation.md的约2万元默认建议和明确客户覆盖规则执行，正式建议包检查目标偏差与上限。税费、撰稿、服务等费用范围写清，未确认是否含税时不套税率。PDF、推荐媒体Word和内部JSON核算引用同一计划，不能将媒体小计声称为已确认的全年综合服务费。

客户PDF使用业务字段：媒体、内容、时间、次数、执行参考单价/总额及实施条件。推荐媒体Word沿用原资源表，六档价格按目录原价填全，原表缺失才留空，市场价不推算代理档。供应商、实际联系人和毛利不随公开目录分发。内部核算Excel默认不生成/交付；用户明确要求时才导出指定版本。

## 效果与验收

明确可交付：内容及刊发数量、题目覆盖、排期、证据归档与复测次数。自然提及、可观察引用及事实准确性的改善是需复测的目标；基线不足时先建立基线，再定目标。曝光、咨询、成交缺少可靠历史数据时不作数值承诺。

交付前检查两个PDF和推荐媒体Word的中文、原格式、续表、页码与六档原价，客户正文只有业务情况和方案。内部核算不进交付清单；用户明确要Excel时才检查指定版本后另交。
