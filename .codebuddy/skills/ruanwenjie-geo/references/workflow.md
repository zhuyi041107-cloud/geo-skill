# 客户输入与问题设计

## 读取已有资料

客户素材表通常在“客户素材清单”F列填写答案：第3至7行为客户、平台、目标、区域、预算，第8行为重复表头，第9行起为详细素材。以字段文本及真实非空答案为准，保留原位置，区分填写说明、示例和客户答案。空白表示未提供，不能据此判定企业没有官网、案例、服务或资质。

先提取品牌与法律主体、核心业务、实际服务范围、目标客群、地域、公开资产及获客目标。客户最新明确纠正覆盖冲突的旧描述，相关问题与方案一并更新；只补影响当前判断的最小缺项，不要求同事重填整套表。已有回答时直接进入诊断与执行，不重新开始采集。

## 先写采购判断，再拟题

在现有内部底稿回答五件事，再生成问句；用户只要题单时底稿不交付：

| 判断 | 要说明的内容 |
| --- | --- |
| 核心获客任务 | 谁准备购买什么，客户希望获得哪类咨询；独立业务与组合采购分别看待 |
| 选择分歧 | 哪些方案、条件、交付方式或替代选择真正影响决定；价格、部署等按相关性选择 |
| 场景与能力边界 | 哪些是客户明确业务、已核能力、待研究需求；研究需求不等于客户已有能力 |
| 每题答案用途 | 预期得到机构推荐、方案比较、费用判断、知识建议还是品牌评价；能改变哪项具体行动 |
| 首轮取舍 | 为什么先问这些，哪些合并或后续补问；不按产品目录平均铺题 |

每个候选问题再通过三项检验：

1. **真实需求。**谁在什么起点、准备解决什么任务，会自然这样问？没有真实咨询记录时是策划假设，不称真实高频。
2. **具体诊断用途。**回答能检验主营认知、主体误认、自然候选、相关同行的选择理由或关键采购判断；只写“覆盖业务”不够。
3. **信息增量。**相较已保留题，能新增什么观察并改变哪项动作？预计判断和后续动作相同的合并。

从没有听过品牌的人出发拟自然需求题，保留实际采购需要的条件。品牌认知题可以按需点名，用于主营与产品归属核准；与自然采购题分开统计。目标是服务商候选时采用自然的“有哪些公司／找谁做”，工具探索不能自动算服务商推荐。

在现有问题备注中写明诊断用途和预期回答形态，人工表仍只交三列。按下面的取舍拟题：

- **获客问题给出购买任务。**“遇到困难怎么办”通常会得到自助方法；只有希望观察服务商选择时，才把真实服务需求写清并询问可考虑的机构。保留有独立价值的知识问题，但品牌未出现不算推荐失败。
- **一题承担一个主要判断。**“需不需要服务”与“推荐谁”分别回答不同决策；按本轮价值保留更关键的问法，不机械拆题增加数量。收费题限定实际服务范围，避免不同业务或交付方式的价格混在一起。
- **品牌认知允许行业锚点。**名称与普通词或其他行业品牌重名时，以“提供某类服务的某品牌”检验行业内认知；裸品牌题只用于名称辨识。两种结果分别解释，不能把裸词歧义直接等同于不认识该行业品牌。
- **比较题检验选择理由。**客户正在比较且确实相关的同行，可按同一购买场景询问差异；没有已知同行时比较真实替代路线，不编品牌名单或为了类别配额强加对比题。
- **合规和风险题保持独立用途。**它们检验选择门槛与信任条件。主动问出的风险主题不自动成为全部自然需求的主导问题，不能据此把整批内容改成合规科普。

地点有实际交付或决策差异才拆题；组合场景有独立决策价值才保留。不把客户卖点、品牌名或专属条件塞入自然题诱导出现，也不把素材表逐字段改成问句。行业科普、术语和知识问题仅在支持本次采购判断时保留，未提客户不自动算推荐失败。

保留无法再合并、能改变具体判断的问题后即停止。**不设固定题数、不按分类配额、不要求问遍产品目录，也不为缩题漏掉独立核心业务。**每题主要承担一个决策意图，真实约束仍准确保留。

## 人工采集表与说明

对同事只提供“问题、引用截图、答案”三列，按平台分文件，问题预填；内部编号、类型及条件不成为人工必填项。说明保持三步：

1. 每个平台一份表，文件名写平台；逐题新建对话，照问题提问。
2. “引用截图”粘贴来源截图或填截图附件名；“答案”粘贴完整回答。没有来源写“未展示”，失败如实注明；长答案另存文本附件并写位置。
3. 回传表格与附件，无需另填URL清单、时间、模式、联网、模型或品牌判读。

截图锚点偏到同一行的问题／答案列时由WorkBuddy内部关联。个别无法可靠对应的截图保留待核状态，继续使用有据回答；看不到完整URL仍分析可见标题、站点与来源结构，不编造链接或把整理任务交回用户。

已明确历史记录照实保留。缺少条件时沿用本轮日期、网页端联网的业务约定，并在内部注明约定来源；具体模型、精确时间及实际联网状态未知的保持未知，不写成已实测条件，也不因此补问或补采。

## 回传后直接完成

收到任一平台回答，读取 [报告分析思路](report-thinking.md)、[证据与规划](evidence-and-planning.md) 及 [固定页式生成说明](template-generation.md)，完成本轮诊断、执行方案和分类预算，不检索或推荐具体媒体。范围以已取得回答为准，未回传平台不补0、不催补，也不追问模式联网后才继续。

回传后先比较品牌印象与相关同行的选择理由，再用真实优势确定核心商业场景；主体、合规和售后说明与场景内容并行。执行方案按权威、行业、自媒体三类说明用途和计划刊次，提供同范围普通／高权重两档，具体媒体与两档资源权益差异待确认。交付两个固定页式PDF，不生成推荐表。客户成稿独立重写为品牌现状、业务影响和执行安排，不附采样基础、样本免责声明或判读教程。内部记录与客户JSON的职责见生成说明。

每客户使用独立目录，保留输入原件及旧成品。project、analysis、plan、证据与核算放.work；report.json单独承载客户可见成稿，正式输出只放两份PDF。示例是虚构测试材料，客户数据不写回技能仓库；本流程不自动采集或操作云端GEO系统。
