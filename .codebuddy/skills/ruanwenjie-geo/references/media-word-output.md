# 推荐媒体 Word 输出

按客户业务完成广泛媒体推荐后，另交付 `推荐媒体.docx`。使用 `templates/推荐媒体模板.docx` 的网络媒体清单、自媒体清单，不重新设计封面。模板由用户指定的原媒体投放表转换，只保留表头与空数据行，不包含案例媒体及价格。

```powershell
python scripts/export_media_word.py --analysis "项目/analysis-final.json" --plan "项目/plan.json" --output "正式输出/推荐媒体.docx"
```

需要 python-docx。Word只读取 `analysis.project` 的客户信息和 `plan.media_recommendations` 独立推荐池，不要求分析预算存在、匹配或达到约2万元。推荐池数量由业务、受众、地域、题材与发布条件决定，不受预算、媒体单价、刊次或执行排期限制。预算内实际投放仍在 `placements` 单独核算，不能用它代替广泛推荐。独立池缺失或为空会明确报错，应先完成推荐池再导出；已有文件拒绝覆盖，改用新的输出目录。

## 填表步骤

1. 遍历 `plan.media_recommendations` 全部推荐资源。按业务筛选相关检索的完整结果，使用 `media.py --limit 0` 取尽匹配，检查 `truncated=false`；不能只检查默认30条后就结束。状态用 `推荐`、`候选`、`需核实`，省略时默认为推荐；取消、排除及明确拒发GEO的资源不导出，其余未知状态报错。按 `source_sheet` 真正分至网络媒体报价、自媒体报价，不按名称或 `media_type` 猜归属。同一来源表与媒体ID只列一次，首次出现顺序不变；同一媒体有相互冲突的属性或报价，先统一来源。
2. 将 `media_id + source_sheet` 与内置目录准确匹配，自动补充分类、地区、备注、入口形态及原表六档价格：市场价格、超级代理、核心代理、高级代理、普通代理、普通会员。匹配到目录时媒体名与市场价必须一致；外部已知资源可直接提供这些字段。`media_type` 不能替代来源表归类。备注保留实际刊发形态，不能把自媒体号写成媒体编辑部稿件。
   更新外部报价的 `source_file` 文件名明确不同于目录源文件，且提供有效 `quotation_date` 与 `market_price` 时，优先使用该推荐项的外部报价及属性，不再用旧目录覆盖或补充；缺少这些依据则继续严格核对内置目录。原目录备注与补充发布条件合并保留；有条件的GEO稿或状态为需核实时，备注须保留“尚未确认可发”的边界，不能一律称已核可发。
3. B列写 `media_group`，表示本计划的媒体组合分组，如本地资讯、行业垂直；相邻同组单元格合并。未提供时只写可证的网络媒体或自媒体，不套用原案例的地域、行业分组。
4. 原16/17列表头及顺序全部保留。六档默认逐项读取内置目录原值，无需在plan手填。市场价格也可取明确的 `market_price`、`market_reference_price`，不使用 `client_unit_price`、`unit_price` 代填。外部 `tier_prices` 中有值的档位须带 `tier_price_source`，仅覆盖相应已知报价；空值不推导新价格。按第2步整体替换为更新外部报价时，未提供的档位留空，不混用旧目录价格。目录缺价保持空白，不按市场价或折扣反推。六档是原表报价，默认建议预算仍取市场参考价，不自动认定为采购成本或已确认客户售价。
5. 联系方式列的原意是稿件可否带联系方式，写 `contact_policy` 的带、不带、可带、不可带或需确认等政策；不能写联系人的姓名、电话、微信或邮箱。文章案例、新闻源、简介、粉丝、认证、认证主体均按已有证据填，未知为空，不从媒体名猜测。

## 推荐池字段

每个 `media_recommendations` 项须有 `media_id`、`media_name`、`source_sheet`，可沿用目录查询记录，再写清业务适配理由。已有目录字段及六档价格自动补齐，其余缺依据的字段留空；不要求内容ID、刊次、费用或排期。以下补充字段不改变原表列序。

| 字段 | 用途 |
| --- | --- |
| `status` | 推荐、候选或需核实；取消、排除不导出 |
| `recommendation_reason` | 具体业务、受众、地域或内容适配理由，保留在内部推荐池，不新增模板列 |
| `media_group` | B列的本次策略分组 |
| `category`、`region`、`editorial_note`、`entry_type` | 分类、地区、真实限制和刊发形态；可由目录补充 |
| `market_price` / `market_reference_price` | 市场参考单价；与客户执行价分开 |
| `tier_prices` | 可含原表六档中文名的已知金额对象；内置查询返回全部六档，Word默认从目录自动补齐 |
| `tier_price_source` | 显式填入外部档位报价时提供原文件、sheet、行及档位等依据；内置查询自动携带原价来源 |
| `contact_policy` | 稿件可否带联系方式 |
| `article_example`、`news_source`、`description` | 已有文章案例、新闻源、简介 |
| `followers`、`certification`、`certification_subject` | 有依据的粉丝量、认证、认证主体 |

## 版式和验收

两清单按网络、自媒体顺序各起一页，保留合并标题、原“按需选择，按实际发布媒体计算总费用”说明、B列合并分组、黑色细边框与自媒体备注红字。原标题与表头的主题色及tint解算为浅黄褐C4BD97；费用提示为FFC000；I列高级代理保持浅色FDE9D9，未知价格仍为空。A3横向、11磅文字、固定列宽、自动行高；连续页重复标题与表头。数据多时扩展表格，不缩成小字。某清单无所选媒体时保留该清单的完整表头和一个空行。

导出后渲染并查看全部页面，逐表核对网络/自媒体各自的完整推荐数量、分组、媒体名称、原表六档价格及真实缺价空白，检查无缺字、截断、重叠或边界溢出。推荐池不表示全部购买；实际刊发数量、排期和总费用使用执行方案与内部 `placements` 的同源核算，不要求另交Excel。
