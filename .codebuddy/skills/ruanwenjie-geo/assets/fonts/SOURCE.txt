The packaged fonts were instantiated from the locally installed OFL-licensed
NotoSansSC-VF.ttf at weight 400 (Regular), using already installed
fontTools. The original font was not changed. Embedding flag fsType was 0.
Copyright and license records were preserved; the Reserved Font Name 'Source'
is not used for the modified font's primary name.

To keep distribution compact, static fonts were subset to broad Unicode
coverage: Latin, Greek, general punctuation, currency/math/arrows, enclosed
numbers, CJK radicals/symbols/strokes, all source-supported CJK Unified
Ideographs basic and Extension A, compatibility ideographs and full-width
forms. This is not a subset based on one customer or this example document.
Hinting and unused advanced/vertical layout tables were removed for PDF use.
All source-supported characters in these ranges were verified to remain.

PDF generation embeds subsets of this packaged static TTF with reportlab.
Headings use the same font with size and color hierarchy to keep the install
package small without restricting Chinese character coverage.
End users do not need fontTools, system font installation or a Codex runtime.
